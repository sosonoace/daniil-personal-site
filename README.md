# Особиста сторінка Даниїла

Навчальний статичний сайт з чотирма сторінками: головною, сторінкою «Про мене», галереєю та контактами.

## Структура

- `index.html` — головна сторінка сайту.
- `about.html`, `gallery.html`, `contacts.html` — інші сторінки з однаковим меню.
- `css/style.css` — стилі та адаптивне оформлення.
- `js/script.js` — мобільне меню та автоматичний рік у підвалі.
- `images/` — зображення сайту.

## Локальний перегляд

Розпакуйте/відкрийте папку проєкту та відкрийте `index.html` у браузері. Залиште папки `css`, `js` та `images` поруч із HTML-файлами.

## Публікація через GitHub Pages

1. Створіть порожній публічний репозиторій на GitHub.
2. У Git Bash перейдіть до цієї папки та виконайте `git init`, `git add .`, `git commit -m "Початкова версія сайту"`.
3. Додайте адресу свого репозиторію як `origin`, перейменуйте гілку на `main` і виконайте `git push -u origin main`.
4. У репозиторії відкрийте **Settings → Pages**, виберіть **Deploy from a branch**, гілку **main** і папку **/(root)**, натисніть **Save**.
5. Після завершення розгортання адреса матиме вигляд `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.

Не додавайте приватний SSH-ключ `id_ed25519` у репозиторій і нікому його не надсилайте. На GitHub додається лише вміст публічного ключа `id_ed25519.pub`.
